# 无形之舞 / THE INVISIBLE CHOREOGRAPHY

**五分钟算法视觉宣传片 · 1920×1080 · 30 fps · 40 镜头 · 中英双语字幕**

算法作为画面的运动规则：光柱重排、搜索空间收缩、城市路径点亮、分形生长、状态复用、频谱分离、曲面上的迭代下降，最终汇入光带与星系。

采用有深度透视的程序化动态图形、逐镜头运镜、发光粒子、立体几何、光幕与光圈转场。中文关键词短暂入场，然后把画面让给算法。底部字幕独立于摄影机运动，保持阅读稳定。

## 观看

成片在会话中单独交付：`the-invisible-choreography.mp4`。视频较大，不写入 Git 历史。

将成片放在 `output/the-invisible-choreography.mp4`，打开 `review.html` 即可观看。MP4 内嵌十章索引；双语字幕已烧录，另提供 `output/subtitles.srt`。

## 一键复现

需要 Node.js 22+、Python 3.11+、FFmpeg（libx264 + AAC）。建议至少 8 GB 内存。

```bash
npm ci
python3 -m pip install -r requirements.txt
bash scripts/setup-fonts.sh
npm test
npm run score
npm run render
```

默认 1080p / 30 fps / H.264 CRF 20 / AAC 320 kbps，分为四个 75 秒片段渲染后无损拼接画面。
默认最多两个并发渲染进程，定期回收原生帧内存。低内存设备可用 `JOBS=1 npm run render`。

```bash
# 检查关键帧
npm run stills
# 只看指定镜头，编号为 0–39
npm run stills -- --shots 2,5,13,15,24,27,36,39
# 快速生成 720p 版本
WIDTH=1280 JOBS=1 npm run render
# 恢复一个失败片段，编号为 0–3
node --expose-gc scripts/render.cjs --chunk 1
# 四个片段均已完成时，只做音画封装
node scripts/render.cjs --mux
```

同一输出目录不要同时启动多个完整渲染任务。不同分辨率或帧率的片段不可混用。

## 配乐

原创合成电子配乐，无第三方歌曲或音频采样；没有旁白。

- **128 BPM / 640 拍 / 160 小节 / 300 秒**。
- 一个镜头 **7.5 秒 = 16 拍 = 四小节**；所有剪辑点对齐小节。
- 引子、节奏进入、抬升、张力、留白、推进、频谱高潮、下降、克制、终章释放，共十段编排。
- 合成弦乐铺底、分解和弦、主旋律、钟音、低音、底鼓、军鼓、踩镲、上升音效与低频落点。
- 48 kHz 立体声，延迟和混响在合成中完成，尾声以延音与三秒淡出收束。

## 计算正确性与视觉边界

`src/algorithms.cjs` 中的实际计算结果驱动图形，不使用伪造的排序、频谱或最短路数据。

- 排序验证最终有序、每轮有序段及元素守恒。
- 二分验证候选范围缩小并找到目标。
- Dijkstra 验证相邻路径、无障碍、路径代价与距离相等，以及每条边的距离不等式。
- 动态规划右/下路径计数结果为 `C(26,13) = 10,400,600`。
- FFT 峰值位于频率箱 3、7、13，幅度分别为 1、0.6、0.3。
- 梯度下降验证每一步目标值不增。
- 40 个镜头边界和中段均做渲染检查；检查每条字幕的安全宽度。

复杂度曲线为增长趋势示意，不是运行时间基准。分形、光带和星系为视觉隐喻；它们不是对真实天体运动的模拟。

## 项目结构

| 文件 | 用途 |
|---|---|
| `src/story.cjs` | 40 条中英双语脚本、镜头关键词 |
| `src/algorithms.cjs` | 排序、二分、Dijkstra、DP、FFT、梯度下降 |
| `src/film.cjs` | 3D 投影、材质、粒子、分形、摄影机与转场 |
| `scripts/score.py` | 音色合成、十段编曲、立体声混音 |
| `scripts/render.cjs` | 分段渲染、字幕、章节、音画封装 |
| `scripts/test.cjs` | 算法与画面边界验证 |

字体为 Noto Sans SC，使用 SIL Open Font License，见 `assets/OFL.txt`。静态字重由官方可变字体生成，以避免渲染器对可变字体字重的兼容问题。
